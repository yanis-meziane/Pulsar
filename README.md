# Pulsar

## Présentation 

*Pulsar* est un projet personnel ayant pour objectif de faire un suivi de statistiques de mes performances en ultimate. 



## Installation du projet 

*1/Récupération du projet en local*

```shell
git clone <url_du_projet>
````

*2/ Installation des dépendances*

```shell
npm install
```

*3/ Lancement du projet*

Il sera nécessaire de lancer deux terminal. 

Frontend :

```shell
cd frontend
npm run dev
```

Backend : 

```shell
cd backend
node server.js
````
